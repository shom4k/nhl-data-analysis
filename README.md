# Анализ статистики команд NHL

**Автор:** Ибрагимов Шамиль  
**Дата:** 13.10.2026

## О проекте

Отборочное задание по анализу данных на Python. Исследуется статистика команд NHL по сезонам: проверка качества данных, расчёт статистических показателей, группировка, визуализация и интерпретация результатов.

## Данные

Источник: [Scrape This Site — Hockey Teams](https://www.scrapethissite.com/pages/forms/).

Файл `Data/hockey_raw.csv` собран самостоятельно из открытого источника с разрешения организаторов. Он не является оригинальным приложением к заданию. Таблица содержит 582 строки и 9 столбцов. Одна строка соответствует выступлению одной команды в одном сезоне.

## Инструменты

## Как запустить

1. Откройте `nhl_analysis.ipynb` в Jupyter Notebook или Google Colab.
2. Убедитесь, что CSV расположен по пути `Data/hockey_raw.csv` относительно рабочей директории ноутбука (в Colab при необходимости загрузите папку и файл).
3. Установите зависимости при необходимости: `pip install pandas matplotlib`.
4. Запустите все ячейки сверху вниз.

## Основные результаты

- В данных 35 уникальных команд, 21 доступный сезон и нет повторений пары «команда — год».
- В `ot_losses` обнаружено 224 пропуска (38,49% строк); остальные столбцы не содержат пропусков.
- Средняя доля побед составляет 0,459, медианная — 0,463.
- Корреляция между разницей шайб и долей побед — 0,887; связь сильная положительная, но не без исключений.
- За 2004 год нет наблюдений, что отражено разрывом на временных графиках.

Подробные вычисления, таблицы, графики и письменные выводы приведены в ноутбуке.
